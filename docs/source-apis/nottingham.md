# Nottingham — not published

The requested [council tree layer](https://maps164.nottinghamcity.gov.uk/server/rest/services/Core_services/Environment/MapServer/42) permits public queries. Its copyright notice includes Ordnance Survey rights and makes use subject to conditions. The council's [mapping terms](https://maps.nottinghamcity.gov.uk/terms/) permit viewing but explicitly prohibit copying and redistribution of licensed data.

The separate [open-data geoportal](https://geoportal-nottmcitycouncil.opendata.arcgis.com/) uses OGL by default. That default does not establish permission for this specific inventory. Tree Atlas does not acquire or publish Nottingham records. Integration requires a matching openly licensed export or explicit permission.

If reuse is authorized, retain felled and proposed status. `CROWN_SPREAD_RADIUS` is a radius in metres, not a crown diameter. `HEIGHT_N` uses metres. The inspected layer does not expose a DBH field, despite a description that mentions diameter observations.

See the [UK source review](../uk-source-review.md) for the licensing decision. Do not present this source as a working inventory view.
