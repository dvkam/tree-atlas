# poznan

Reviewed 27 October 2026. Status: not published.

[Official source](https://geopoz.poznan.pl/geo/aktualnosci/1719,Roslinnosc-w-Modelu-3D.html).

The official 3D model and public configuration expose inventoried vegetation and separate remote-sensing layers. The map offers area-based exports. This review did not verify a complete repeatable individual-tree export with applicable redistribution terms. LiDAR trees must not be presented as species inventories.

Do not infer a licence from public access. Add this location only after the missing source contract is verified. See [north expansion review](../expansion-north.md).

## Tested alternatives

Inspected https://sip.poznan.pl/model3d/app.config.json and its public modules. They distinguish inventoried trees and point-cloud vegetation and expose area-based model export tools. That does not establish complete licensed inventory access.
