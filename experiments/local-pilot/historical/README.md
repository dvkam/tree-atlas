# Historical pilot reports

These are selected original 7–8 November 2026 reports, archived during the local branch import on 19 November. Read [the evidence policy and path mapping](../HISTORICAL-EVIDENCE.md) before using them. They are not fresh branch test results.

[index.json](index.json) records each retained file's source SHA-256 and size. All non-summary files were copied directly from the original local folders and compared with the import manifest. The two compact summaries identify their full original reports by SHA-256. The sealed contract and its own evidence remain untouched outside this archive at `../tree-atlas-contract-v1`.

New runtime reports are generated at the usual component paths and ignored. Do not copy a later green report into this historical snapshot or change its date to imply a new run.
